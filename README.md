# Asian Market — Grocery App

> Interactive app prototype for Asian grocery markets, featuring imported product sections, daily ready meals and in-house recipes.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Asian grocery retail

Interactive app prototype for Asian grocery markets, featuring imported product sections, daily ready meals and in-house recipes.

**Highlights**

- Browsable sections of imported goods
- Ready-made dishes cooked daily in the store kitchen
- Step-by-step in-house recipes

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
